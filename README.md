# Maintenance Telegram Bot

This bot implements work with equipment and maintenance requests in [Odoo ERP](https://github.com/odoo/odoo).
This project is not a module for [Odoo ERP](https://github.com/odoo/odoo) and works separately.

## Third party
This project is based on the source codes of the following projects:
- [aiogram-bot-template by Forden](https://github.com/Forden/aiogram-bot-template)
- [aiogram_dialog examples by Tishka17](https://github.com/Tishka17/aiogram_dialog/blob/2.2.0/example)
